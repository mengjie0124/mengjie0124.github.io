# Mengjie Zhao — Academic Website

Static source for `https://mengjie0124.github.io/`.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named exactly `mengjie0124.github.io`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages** and confirm **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. The site will appear at `https://mengjie0124.github.io/` after GitHub finishes the first deployment.

No build step or external framework is required.
